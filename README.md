# Grow My Therapy: Dr. Maya Reynolds

A website redesign for Dr. Maya Reynolds, PsyD, alongside a responsive clone of the reference therapy homepage it was based on.

- [Maya's redesign](https://grow-my-therapy-suryansh.pages.dev/) and its [booking page](https://grow-my-therapy-suryansh.pages.dev/contact/)
- [Reference clone](https://grow-my-therapy-suryansh.pages.dev/original/)
- [Source on GitHub](https://github.com/suryanshishere/grow-my-therapy)

Dr. Maya Reynolds is a fictional therapist. The booking forms validate in the browser and send or store nothing.

Built with Next.js, React and TypeScript as a static export, hosted on Cloudflare Pages.

## Run locally

Use Node.js 22 (see `.node-version`).

```sh
npm ci
npm run dev       # http://localhost:3000
npm run build     # static export in out/
npm run preview   # serve out/ on http://localhost:8787
npm run deploy    # publish out/ to Cloudflare Pages
```
